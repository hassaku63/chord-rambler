# 用語集

画面と文書で使う語の定義。語の範囲が教材によって違うものは、`docs/architecture/theory-conventions.md` に採った立場を書いている。

## 音楽の語

| 語 | 意味 |
| --- | --- |
| 主音 | 調の中心になる音 |
| 調 | 主音と旋法の組（C major など） |
| 同主短調 | 同じ主音の短調（C major に対する C minor） |
| 旋法 | 音階の種類（長調、自然短音階、ミクソリディアン、ドリアンなど） |
| 和音名 | 根音と種類で書いた和音の名前（Dm7）。調によらない |
| 度数 | 主音から数えた音階上の位置。ローマ数字で書く（ii7）。音程の大きさには使わない |
| 度 | 音程の大きさを数える語（3 度、長 3 度）。文書でまとめて指すときは「音程の数」 |
| ダイアトニック | 和音を作る音（根音と 2〜7 度の構成音）と 7 度のバスが、綴りで調の音階の音だけでできていること。テンションとほかのバスは見ない |
| 機能 | 調の中での和音の働き。トニック（T）、サブドミナント（S）、ドミナント（D）の 3 つ |
| トニック | 落ち着く働き。I と、その仲間の iii・vi |
| サブドミナント | トニックとドミナントのあいだで、動き出す働き。IV と ii |
| ドミナント | トニックへ向かう緊張を作る働き。V と vii° |
| トニックの仲間 | I と 2 つの音を共有する iii と vi |
| 導音 | 主音の半音下の音。主音へ進もうとする |
| 三全音 | 全音 3 つ分の音程。属七の 3 度と 7 度が作る |
| 借用和音 | 同じ主音の別の旋法にある和音を、今の調で使うこと。セカンダリー・ドミナントは含めない |
| セカンダリー・ドミナント | 主和音以外の調の和音に対して、ドミナントの形をした和音（V7/V など） |
| 解決 | 緊張のある和音が、期待される和音へ進むこと。期待と違う先へ進むことを「変則」と呼ぶ |
| フレーズ | 進行のひと区切り。既定では 4 小節ごと |
| 終止 | フレーズの終わりの和音の動き。正格終止、半終止、変格終止、偽終止 |
| テンション | 七の和音の上に重ねる 9 度・11 度・13 度の音 |
| sus | 3 度を 4 度（sus4）か 2 度（sus2）に置き換えた和音 |
| add9 | 三和音に 9 度を足した和音。7 度を含まない |
| 分数コード | バスの音を指定して書いた和音（C/E、F/G） |
| 転回形 | 分数コードのうち、バスが和音の音であるもの（C/E） |

## このプロダクトの語

| 語 | 意味 |
| --- | --- |
| 進行 | 枠を並べたもの |
| 枠 | 1 つの和音が鳴る区間。和音、長さ（拍）、役割を持つ |
| 区間 | フレーズをまとめた、曲の中の大きな部分（A メロ、サビなど） |
| 役割 | 枠が進行の中で果たす働き。構造的な役割と、色合いの役割がある |
| 構造的な役割 | 機能とフレーズの位置から決まる役割。安定、つなぎ、準備、高まり、解決、締め |
| 色合いの役割 | 印象で決める役割。広がり、浮遊、切なさ、余韻 |
| 候補 | ある枠に置ける和音の提案。理由を伴う |
| 変形 | 同じ根音のまま、七度・3 度の置き換え（sus）・テンションを変えた和音。長・短の入れ替えや、減・増への変更は含めない（C から Csus4 は変形、C から Cm は変形でない） |
| 読み | 和音を調と前後の和音の中に置いて付ける名前（機能、借用、終止など） |
| 根拠の種類 | 説明の項目が何に基づくか。定義、計算、流儀、慣習、連想の 5 つ |
| 流儀 | 読みが従う、特定の教え方の規則の組 |
| 慣習 | よく使われる進行や、移り変わりの好み |
| 連想 | 印象と和声の手段との結びつき |
| 体験 A | グラフ型。末尾に枠を足して、候補から和音を選ぶ |
| 体験 B | 計画型。役割つきの枠を先に並べて、埋める |

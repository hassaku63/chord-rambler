# 0016. 配備するイメージは distroless を基本にする

- 日付: 2026-11-15
- 状態: Accepted（所有者の判断は #53）

## 文脈

所有者は、実際に配備するイメージを、できるかぎり distroless にしたい。理由は CI/CD の速さとセキュリティ。開発用と割り切って公式のイメージを使うことは、検討して許してよい（#53）。

今のイメージは 2 つ（ADR-0010）。`api` は distroless の `static` の `nonroot`、`web` は nginx（`nginxinc/nginx-unprivileged` の Alpine 版）で、起動時にシェルで設定のテンプレートを差し込む。

一次情報で確かめたこと（2026-11-15）:

- Docker の公式の指針（https://docs.docker.com/build/building/best-practices/ ）は、信頼できる出どころから作られた小さなベースイメージを選ぶよう勧める。小さいイメージは取得が速く、依存から入る脆弱性を減らす。ビルドとテスト用と、本番用（ふつうはより細い）とでベースイメージを分けることを考える、ともある。distroless という語はなく、`FROM` の節では Alpine を挙げている。
- Google の distroless（https://github.com/GoogleContainerTools/distroless ）は、アプリと実行時の依存だけを含み、パッケージマネージャーやシェルを含まない。実行時のコンテナを要るものだけに絞ることを、長く本番で使われてきたベストプラクティスとし、脆弱性のスキャナーの信号と雑音の比が上がるとする。シェルが要るときのために `:debug` の像がある。nginx の像はない。
- Docker Hardened Images（https://docs.docker.com/dhi/ ）は、distroless の版を含む Docker 自身の最小のイメージで、小さいイメージは取得と起動が速いとする。取得には Docker のアカウントでのログインが要る。
- Google Cloud の指針と NIST SP 800-190 は、開発環境のネットワークで許されていないホストにあり、開けなかった。

CI/CD の速さについて: 配備の側（イメージの取得）では効く。今の CI はイメージを取得せずビルドし、時間のほとんどは Go と Node のビルドの段にかかるので、効果は小さい。

## 決定

1. **配備するイメージは distroless を基本にする。** シェルとパッケージマネージャーを持たない実行用のベースに、ビルドした成果物だけを載せる。
2. **開発と手元の確かめに使うイメージは、公式のイメージを使ってよい。** ビルドの段、compose の開発用のサービス、デバッグ、設定のテンプレートの差し込み、開発用のデータベースの初期化など。
3. **distroless にできない配備用のイメージは、理由を ADR に書く。**
4. **今の `web` は、配備先を決めるまで、開発と手元の確かめ用と位置づける。** 配備先を決める企画で、画面を静的な配信に置くか、distroless の配信のイメージにするかを決める。

ADR-0010（2 つのイメージ、実行用のベースのタグと digest での固定）は置き換えず、この方針を足す。

## 検討した選択肢

- **方針を置かず、イメージごとに決める**: 今の ADR-0010 のまま。イメージを足すたびに、同じ検討を繰り返す。
- **`web` を今 Docker Hardened Images の nginx にする**: distroless に近づく。CI と手元の両方でログインが要り、秘密情報を CI に置くことになる。nginx の像の有無とテンプレートの差し込み方を、まだ確かめていない。
- **`web` を今 Go の小さな配信サーバーにして、distroless に載せる**: 2 つとも distroless になる。ADR-0010 で外した案（配信の規則をコードに持ち込む）に近い。

## 結果

- 配備用のイメージに入るものが減り、入られたときにできることと、スキャナーの報告の量が減る。
- シェルがないので、配備したコンテナの中で調べものができない。調べるときは `:debug` の像か、手元のイメージを使う。
- `web` は、配備先を決めるまで方針から外れたままになる。
- 再検討の条件: 配備先を決めるとき。distroless の像のない実行環境（言語や配信のサーバー）が要るとき。

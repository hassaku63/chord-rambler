# エンジンの構成

決定論的に呼び出せるエンジンの、概念上のまとまりと責務。決定の理由は ADR-0005。読みの規則と出どころは `docs/architecture/theory-conventions.md`、語の定義は `docs/glossary.md`。

## 土台: 進行のモデル

すべてのまとまりが読み書きするデータ（ADR-0006）。

- **調**: 主音と旋法。進行は調を 1 つ持つ。長調は C、G、D、A、E、B、F♯、D♭、A♭、E♭、B♭、F の 12 個。
- **拍子**。
- **進行**: 区間、フレーズ、枠の入れ子。区間は 1 つ。フレーズの区切りの既定は 4 小節ごとで、進行の最後は 4 小節に満たなくてもフレーズの終わりとする。
- **枠**: 1 つの和音が鳴る区間。次を持つ。
  - 和音。絶対の和音で持つ。「和音なし」（鳴らさない）と「まだ選んでいない」を区別する。
  - 長さ（拍）。既定は 1 小節。枠は拍の頭から始まる。
  - 役割（任意）。
- 小節の位置は、枠の長さを足して導く。
- 枠の操作は、追加、差し替え、挿入、削除。体験 A（グラフ型）と体験 B（計画型）は、同じ進行に対する別の操作で、どちらもこの操作を使う。
- 移調は、主音とすべての和音の根音を、同じ音程だけ動かす。

### 役割

| 種類 | 役割 | 決まり方 |
| --- | --- | --- |
| 構造 | 安定 | トニック |
| 構造 | つなぎ | 前と同じ機能のまま、別の和音で続ける |
| 構造 | 準備 | サブドミナントで、次がドミナント |
| 構造 | 高まり | ドミナント |
| 構造 | 解決 | ドミナントのあとのトニック |
| 構造 | 締め | フレーズの終わりの終止 |
| 色合い | 広がり、浮遊、切なさ、余韻 | 連想のデータ（まとまり 6） |

構造的な役割は、役割から候補を出す向きと、埋まった枠に札を付ける向きの両方に使う。色合いの役割は、役割から候補を出す向きだけに使う。

## まとまり

下のまとまりは、上のまとまりを知らない。

| 素材 | 1. 音の素材 | 音名と音程、音高の集合、和音、音階、移調 | 定義 |
| 素材 | 2. 表記 | 和音名とローマ数字の読み書き、表示用の綴り | 規約 |
| 分析 | 3. 関係の計算 | 和音と調、和音と和音の関係 | 計算できる事実 |
| 分析 | 4. 読み | 機能、種別、終止、解決、テンションの扱い | 流儀による規則 |
| 知識 | 5. 慣習 | 定番の進行、移り変わりの好み、様式 | データ |
| 知識 | 6. 意図と手段 | 印象や色合いと、和声の手段との対応 | データ |
| 応用 | 7. 問い合わせ | 候補、変形、説明、要約、役割の札 | 手続き |

### 1. 音の素材

- 音名は、幹音と変化で綴る（重変化を含む）。音程も度数と種類で持つ。
- 綴りを持たない音高の集合を、別の表現として持つ。含む・含まれるの判定はこちらで行う。
- 和音は、根音、根音からの度数の集合、バス（根音からの度数。任意）。調を持たない。
- 種類の名前（m7、sus4）や、三和音の質・七度・テンションという見方は、度数の集合から導く。
- 移調は度数で音名を動かし、綴りを保つ。

### 2. 表記

- 和音名と和音、ローマ数字と「主音から見た位置」を相互に変換する。別名を受け付ける。
- 表示用の綴り（重変化の読み替え）、テンションの書き方、大文字・小文字は、ここの規約として持つ。

### 3. 関係の計算

流儀によらず、定義から計算できる事実だけを返す。

- 和音 1 つと調: 主音から見た位置、調の音階に含まれるか、含む同主旋法の集合、導音や三全音を含むか。
- 和音の並び: 根音の動き、共通音、「調の和音の 5 度上にある長三和音か属七」という形かどうか。
- 時間: 小節とフレーズの中の位置。

### 4. 読み

関係の計算の結果に、流儀の規則を当てて名前を付ける。

- 機能、種別（ダイアトニック、借用和音、セカンダリー・ドミナント）と借り先、終止、解決の仕方、テンションの扱い。
- 結果は、読んだ調を持つ。主な読みのほかに、別の読みを並べられる。画面には主な読みを出し、別の読みは開いて見る。
- 読みは保存しない。進行の全体から毎回導く。
- 規則は 1 か所に集め、規則ごとに出どころを持つ。

### 5. 慣習

- 定番の進行、ある和音のあとに来やすい和音、様式ごとの違いを、カタログのデータとして持つ。進行は、主音から見た位置の列で書く。
- 正誤ではなく好みを表す。「根音が 5 度下がる」はまとまり 3 の事実、「強い進行」「定番」はここの評価。

### 6. 意図と手段

- 印象（浮遊感、切なさ）や色合いの役割（広がり）と、和声の手段との重みつきの対応を、カタログのデータとして持つ。一対一に対応させない。
- 構造的な役割（準備、高まり、解決、締め）は、ここではなく、機能とフレーズの位置から導く。

### 7. 問い合わせ

下のまとまりを組み合わせて、画面の問いに答える。

- ある位置の候補（前後の和音、枠の役割、全体の文脈を見る）
- 和音の変形（同じ根音と三和音の質で、七度・sus・テンションを変える）
- 和音 1 つの説明、進行全体の要約、埋まった枠の役割の札

返す値は構造化した事実で、項目ごとに根拠の種類（定義、計算、流儀、慣習、連想）を持つ。

### 8. 文

- 構造化した事実から、日本語の説明文を作る。
- 根拠の種類を文に反映する（理論上こうである／こう呼ぶ／よく使われる／こう感じられやすい）。

### 9. 演奏

- 進行を、再生できる音符の列にする（声部の配置、伴奏の型、テンポ）。
- 採用前の候補の試聴は、今の進行に候補を足した仮の進行を同じ手続きに渡す。

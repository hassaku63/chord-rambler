# ドメインモデル

エンジンが扱う値の型と規約。まとまりの責務は `docs/architecture/engine.md`、語の定義は `docs/glossary.md`。型の振る舞いの正は、コードとテスト（事実の表と、その出どころ）。

## 1. 音の素材

`backend/internal/material`。`NoteName`、`Interval`、`PitchClass`、`PitchClassSet`、`Chord`、`Scale` はフィールドを外に見せず、値はゼロ値か、作る関数（`New` で始まる関数と、移調などの操作）の返すものだけ。幹音 `Letter`、種類 `Quality`、旋法 `Mode` は整数から型変換して書けるので、作る関数が範囲を検査する。ゼロ値は意味のある値になる（音名は C、音程は完全 1 度、音高クラスは C、音高の集合は空、和音は C だけ、音階は C のイオニアン）。

### 音名 `NoteName`

- 幹音（C D E F G A B）と変化の組。変化は半音の数で、−2（重フラット）から +2（重シャープ）まで。オクターブは持たない。
- 範囲の外の変化や、幹音でない文字は作れない（`NewNoteName` がエラーを返す）。
- 異名同音（C♯ と D♭）は別の音名。同じ音として扱うのは、音高クラスに移したとき。
- 文字列からの読み取りと、表示用の綴りは、表記のまとまりが持つ。`String` はテストと記録のためだけ。

### 音程 `Interval`

- 音程の数（1〜13。「3 度」の 3）と種類（完全、長、短、増、減）の組。「度数」（主音から数えた位置、ローマ数字）とは別の語（`docs/glossary.md`）。9・11・13 のテンションのために、複合音程を持つ。
- 1・4・5・8・11・12 度は完全・増・減をとり、2・3・6・7・9・10・13 度は長・短・増・減をとる。成り立たない組（長 5 度、完全 3 度）は作れない（`NewInterval` がエラーを返す）。
- 半音の数（`Semitones`）は、長音階の主音からの音程を完全・長とし、増は半音大きく、減は完全・短より半音小さい。複合音程は、単音程にオクターブ（12）を足したもの。減 1 度（−1）は、このプロジェクトの規約: 増 1 度の逆として置き、同じ幹音で半音下げる動き（C♯ から C）にも名前を付ける。1 度は減らせないとする教科書もある。
- 2 つの音名のあいだの音程（`IntervalBetween`）は、下の音から上の音への単音程（1〜7 度）。音程の数は幹音の数え方で決まり（C–D♯ は増 2 度、C–E♭ は短 3 度）、種類は半音の数で決まる。5 つの種類のどれにも当たらない距離（C♯–E♭♭）はエラー。

### 移調

- 音名に音程を足す（`Transpose`）と、幹音を音程の数の分だけ動かし、残りを変化で埋める。綴りを保つ（E に長 3 度で G♯。A♭ にはしない）。下げる（`TransposeDown`）のも同じ。
- 結果が重シャープ・重フラットを超えるときはエラー。表示のための読み替え（`docs/architecture/theory-conventions.md` の 6）は、ここでは行わない。
- 移調した音名の音高クラスは、元の音高クラスに半音の数を足して 12 で割った余り。上げて同じ音程で下げると元に戻る。

### 音高クラス `PitchClass` と音高の集合 `PitchClassSet`

- 音高クラスは 0〜11（C = 0）。綴りもオクターブも持たない。範囲の外は作れない（`NewPitchClass` がエラーを返す）。音名からは `PitchClass` で移す。
- 音高の集合は、12 の音高クラスの集合。綴りを持たない。含む（`Contains`）、含まれる（`IsSubsetOf`）、和（`Union`）、移調（`Transpose`。半音の数で回し、12 で折り返す）を持つ。
- 鳴る音や調の音階との突き合わせのように、綴りによらない判定はこちらで行う。

### 和音 `Chord`

- 根音（音名）、根音からの音程の集合、バス（根音からの音程。任意）の組。調を持たない。根音は常に構成音で、1 度にあたる。
- 音程の集合は、音程の数ごとに 1 つまで。同じ数の音程が 2 つあるもの（長 3 度と短 3 度、根音のほかの 1 度）と、構成音が重シャープ・重フラットを超えるものは作れない（`NewChord` がエラーを返す）。構成音の音程は 2〜7 度と、テンションの 9・11・13 度。8・10・12 度は、見方が見ない 1・3・5 度を鳴らすので作れない（sus4 に 10 度を足すと 3 度が鳴る）。
- 構成音（`Notes`）は根音から音程の数の順に、移調と同じ綴りで並べる。音高の集合（`PitchClasses`）は構成音のもの。
- バス（`WithBass`）は根音からの単音程（1〜7 度）で、構成音でなくてもよい（C/D）。構成音でないバスは、構成音（`Notes`）と、その音高の集合（`PitchClasses`）と、見方に入らない（C/D を add9 と読まない）。鳴る音の音高の集合（`SoundingPitchClasses`）は、構成音にバスを足したもの。調や音階との突き合わせと再生は、鳴る音の集合で行う（C/B♭ は、構成音では C のイオニアン・リディアン・ミクソリディアンに含まれ、鳴る音ではミクソリディアンだけに含まれる）。重シャープ・重フラットを超えるバスは作れない。
- 移調（`Transpose`）は根音だけを動かし、音程の集合とバスを保つ。綴りは音名の移調と同じ規則で決まる。減 1 度の移調は、ほかと違って下がる。

### 見方

和音の音程の集合から導く。和音に保存しない。6 度と、3 度と並ぶ 2 度・4 度は、どの見方にも出ない（C6 は、見方では C の長三和音と同じ）。名前の文字列（`m7`、`sus4`）は表記のまとまりが作る。見方の型の `String` は定数の名前（`TriadSus4`）を返し、テストと記録のためだけ。

- 三和音の質（`Triad`）: 3 度と 5 度で、長（長 3 度・完全 5 度）、短（短 3 度・完全 5 度）、減（短 3 度・減 5 度）、増（長 3 度・増 5 度）。3 度がなく、完全 4 度か長 2 度が完全 5 度と並ぶものは sus4・sus2（3 度を置き換えた和音。`docs/architecture/theory-conventions.md` の 6）。どれにも当たらないもの（5 度がない、3 度がなく 4 度と 2 度の両方を持つ、など）は「その他」。
- 七度（`Seventh`）: なし、長 7 度、短 7 度、減 7 度。増 7 度は「その他」。
- テンション（`Tensions`）: 9・11・13 度の音程を、9、♭9、♯9、11、♯11、13、♭13 として、音程の数の順に返す。ほかの種類（減 11 度など）は「その他」。add9 は、七度が「なし」でテンションに 9 があるもの。9 の和音は 7 度を含む（`docs/architecture/theory-conventions.md` の 6）。

### 音階 `Scale`

- 主音（音名）と旋法の組。旋法は 7 つの教会旋法（イオニアン＝長音階、ドリアン、フリジアン、リディアン、ミクソリディアン、エオリアン＝自然短音階、ロクリアン）。和声的短音階と旋律的短音階は持たない。
- 旋法は、幹音だけの音階を C から B のどれかで始めたもの（ドリアンは D から）。7 音は幹音を 1 つずつ使い、主音からの音程は、その幹音どうしの音程と同じ。音が重シャープ・重フラットを超える主音と旋法の組は作れない（`NewScale` がエラーを返す）。
- 和音が音階に含まれるかは、音高の集合で判定する（`Contains`）。綴りは見ない。

## 2. 表記

`backend/internal/notation`。文字列と音の素材の値を相互に変換する境界。読んだあとは `material` の値だけを扱い、文字列を持ち回らない。表示の形と受ける別名は `docs/architecture/theory-conventions.md` の 6。

- 音名（`ParseNoteName`、`FormatNoteName`）: 大文字の幹音と、変化記号 1 つ（重変化を含む。重シャープは `𝄪`・`x`・`##`・`♯♯`）。書くときは綴りを保つ（B𝄫 は B𝄫）。
- 和音名（`ParseChord`、`FormatChord`）: 種類は、和音の音程の集合が語彙の種類の音程とちょうど一致するときだけ名前になる。見方からは名前を作らない（C6 は、見方では長三和音だが、名前はない）。語彙にない和音は書けない（`ErrNoName`）。バスは、読むときは根音からの単音程（`IntervalBetween`）にし、書くときは根音を移調した音名にする。書いた名前を読むと、元の和音に戻る。
- 読めない文字列は `ParseError` を返す。読めなかった所（`Rest`）と理由（`Err`）を持ち、理由は `notation` のエラーか、`material` のエラー（重変化を超える構成音、根音との音程がないバス）を包んだもの。
- 表示の綴り（`DisplaySpelling`、`FormatChordForDisplay`）: 書くときだけ、根音を読み替える。根音を読み替えたら、バスは読み替えた根音から同じ音程で書く（B𝄫/D♭ は A/C♯）。根音を読み替えないときだけ、バスを単独で読み替える。読み替えた名前を読むと、鳴る音の集合は同じだが、綴りの違う和音になる（B𝄫 は A）。
- 主音から見た位置（`Position`）: 長音階の度数（1〜7）、その変化（`Flat`、`Natural`、`Sharp`）、和音の形（`Shape`。和音から根音を除いたもの。根音からの音程の集合と任意のバスで、`ShapeOf` で和音から作る）、向かう先の度数（任意。`V7/V` の `/V`）の組。調を持たず、機能や借り先も持たない（読みは関係の計算と読みのまとまりが導く。ADR-0005）。範囲の外の度数と変化、ローマ数字で書けない向かう先は作れない（`NewPosition`、`WithTarget` がエラーを返す）。ゼロ値は、1 の度数に根音だけの形。
- 主音と組み合わせる（`Position.Chord`）: 根音は、主音の長音階のその度数の音を、幹音を保って変化の分だけ動かした音（C で ♭VII は B♭）。主音を、度数の音程（変化があれば、半音広げた・狭めた音程）で移調して求めるので、綴りは移調と同じ規則で決まる。向かう先があれば、向かう先の度数の音を主音にして数える（C で V7/V は D7）。根音・構成音・バスが重変化を超えるときはエラー。
- ローマ数字（`ParseRoman`、`FormatRoman`）: 表示の形は `docs/architecture/theory-conventions.md` の 6。和音の形が語彙の種類（とテンション）にちょうど当たるときだけ書ける（`ErrNoName`）。バスのある位置は書かない（`ErrRomanBass`）。書いた文字列を読むと、元の位置に戻る。読むのは表示の形だけで、読めない文字列は和音名と同じ `ParseError` を返す。

# 説明の文の規則

エンジンが返す事実、カタログのデータ、説明の文が守る線。何を誤りとし、何を教育上の単純化として許すか。決定の理由は ADR-0012。まとまりの責務は `docs/architecture/engine.md`、採っている流儀は `docs/architecture/theory-conventions.md`、語の定義は `docs/glossary.md`。

## 基準

説明の文は、詳しく言い直すときに取り消さずに済むこと。このアプリで作れる進行の中に、その文が偽になる場合があってはいけない。

- 許す例: 「ドミナントは、トニックへ進もうとする緊張を作る」（進まなくても偽にならない）
- 許さない例: 「ドミナントのあとはトニックへ進む」（V → vi で偽になる）

既定で何を出し、何を開いて見せるか（説明の粒度）は、ここでは決めない。この文書の規則は、どの粒度でも守る。

## 許す単純化

1. 主な読みを 1 つだけ出す。別の読みは開いて見る。
2. 採っている流儀の中で言う。「vi はトニックの仲間」と書き、文のたびに「この流儀では」と断らない。別の立場があることは、別の読みと同じく、開いて見る側に出す。
3. 細部と例外を省く（声部の動き、転回形による違い、様式による違い）。
4. 理由を 1 つに絞る。候補の理由は、いちばん効いているものを言う。
5. 用語集の語だけで言う。
6. 働きをたとえで言う（「進もうとする」「落ち着く」）。用語集の定義にある言い方に限る。

## 根拠の種類ごとの言い方

| 根拠 | 言い方 | 例 |
| --- | --- | --- |
| 定義、計算 | 言い切る | 「Dm7 は D・F・A・C でできている」「根音が 5 度下がる」 |
| 流儀 | 呼び名か働きとして述べる | 「借用和音と呼ぶ」「ドミナントとして働く」 |
| 慣習 | 頻度として述べる。正誤にしない | 「よく使われる流れ」「定番ではない」 |
| 連想 | 傾向として述べる。言い切らない | 「浮遊して感じられやすい」 |

理論上の説明（定義、計算、流儀）と、期待する印象（連想）は、分けて出す。

## 許さない誤り

| # | 誤り | 例 |
| --- | --- | --- |
| 1 | 鳴る音と合わない。和音名・構成音・度数が、その枠の和音と合わない。再生される音が和音と合わない | C major の F を「V」と書く。Csus4 と書いて 3 度を鳴らす |
| 2 | 前後や位置についての主張が、進行と合わない | 次が IV なのに「I へ解決する」と書く。フレーズの途中の V → I を「終止」と呼ぶ |
| 3 | 根拠より強く言う。流儀・慣習・連想を、定義や計算と同じ言い方で述べる | 「sus4 は浮遊感を生む」「V のあとは I に進む」「ここで IV は使えない」 |
| 4 | 呼び名の誤用。進行の名前を、その名前を決めている特徴を欠く進行に付ける。用語集と違う意味で語を使う。採っていない流儀の語を使う | 「カデンツ」を機能の型の意味で使う |
| 5 | 1 つの画面の中での食い違い | 候補の理由と、採用したあとの説明が違う。役割の札と説明が違う。和音名とローマ数字が違う |

## ユーザーの選択への言葉

- ユーザーが選んだ和音や進行を「誤り」「間違い」と言わない。
- 慣習から外れていれば「定番ではない」「変則」、音がぶつかれば「濁りやすい」と、事実と注意までを述べる。
- 実際の動きのとおりに説明する。解決しないものを「解決する」と書かない。

## 言えないとき

読みの規則に当たらない和音に、それらしい名前を付けない。計算できる事実（構成音、主音から見た位置、調の音かどうか）だけを述べる。

## 止め方

誤りは、次の仕組みで止める。検査は、それぞれのまとまりを実装するスライスで足す。

| 誤り | 仕組み | まとまり |
| --- | --- | --- |
| 1 | 理論の事実のテーブル駆動テスト（出どころつき）。和音名とローマ数字の読み書きの往復。再生する音が和音の音高の集合に収まり、和音を決める音（3 度か sus の音、7 度）を含むことの検査 | 音の素材、表記、関係の計算、演奏 |
| 2 | 読みは保存せず、進行の全体から導く。解決と終止の事実は、次の和音とフレーズの位置を入力に取る。列挙した進行で、事実が述べる先と実際の次の和音が一致することを検査 | 読み、問い合わせ |
| 3 | 文の型は根拠の種類を受け取り、種類ごとに使える言い方を表で決める。表にない組み合わせはテストが落ちる。カタログの項目は種類（慣習か連想か）を持ち、読み込みで検査 | 慣習、意図と手段、文 |
| 4 | カタログの進行の名前は、名前を決める特徴と出どころを持ち、特徴の一致でだけ付ける。文の型に出る理論の語が用語集にあることを検査 | 慣習、文 |
| 5 | 候補の理由と採用後の説明を、同じ事実から作る。列挙した進行で、候補として出したときの事実が、採用後の説明の事実に含まれることを検査 | 問い合わせ |

機械で見ないもの（文の自然さ、単純化が誤解を招かないか）は、文の型を足す・変える PR のレビューで、基準に照らす。使って見つけたものは、観察の Issue にする。

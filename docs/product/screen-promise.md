# 画面の約束

目標の画面が、どの区画で何を見せ、何をさせるか。決定と理由は ADR-0019。今の画面の構成は `docs/architecture/screen.md` にある。今の画面は 2 の骨組みとタブ、4 の点 1・3・4 までを満たし、枝の一言（4 の点 2）、元に戻す、移調をまだ持たない。

目標の画面を作る Issue を `ready` にするときと、目標の画面の E2E（`frontend/e2e/`）と画面レビュー（`.claude/skills/ui-review/SKILL.md`）は、この文書を基準にする。

- 前提は PC の横長の画面。
- 「〔#203〕」「〔#204〕」の印のあるものは、その企画で決まるまで、5 の暫定で動く。6 に挙げたことは、まだ決まっていない。ほかは、ADR-0019 の判断と、そこから導いた約束。
- 語は `docs/glossary.md` の語を使う。画面に出す見出しやボタンの文言は、ここでは決めない。

## 1. 満たす体験

| | 体験 | 出どころ（`docs/product/concept.md`） |
| --- | --- | --- |
| E1 | **比べて選ぶ。** 意図の違う少数の候補を、理由（理論上の説明と期待する印象）と音で比べ、自分で 1 つ選ぶ | 2 章の 1、4 章の A、6 章 |
| E2 | **置いたら聴き、聴いたら直す。** 選ぶ前後に、前後の流れの中で音を確かめる | 2 章の 2、5 章 |
| E3 | **全体と、今いじっている 1 点が同時に見える。** 流れ（機能、終止）、区切り（フレーズ、区間）、選んでいる枠が、1 つの視野にある | 1 章、3.4、4 章 |
| E4 | **意図から手段へ。** 区間や枠に役割を置き、それを満たす手段を選んで埋める | 2 章の 3、4 章の B |
| E5 | **何度でも戻り、比べられる。** 差し替え、変形、やり直し、移調が軽い | 2 章の 5、3.4、5 章、7 章 |

## 2. 骨組み

1 つの画面に、キャンバス、帯、文脈の欄を同時に置く。上に、探索のタブと計画のタブ。

```
┌ 探索のタブ │ 計画のタブ ─────────────────┐
│ キャンバス（流れ）            │ 文脈の欄     │
│                              │（選んでいる  │
├──────────────────────────────┤  ものに追随）│
│ 帯（時間と再生）              │              │
└──────────────────────────────┴──────────────┘
```

図は区画の関係だけを示す。

- 2 つのタブは、同じ進行に対する 2 つのやり方。タブを切り替えても、進行は変わらない。
- 調の選択と、元に戻す操作は、どちらのタブでも同じものを使う。調を変えると、進行を移調する（コンセプトの 3.4。和音どうしの音程の関係を保ち、和音名が変わる）。元に戻すと、進行を変えた操作を戻せる。
- 文脈の欄は、選んでいるもの（枝、本線のノード、枠）が変わると、その中身に替わる。全体（キャンバスと帯）と、スクロールなしで同時に見える。

## 3. 区画ごとの約束

### キャンバス

| 項目 | 約束 |
| --- | --- |
| 主目的 | 進行の流れ（和音のつながりと、その意味）を見せる。探索のタブでは、次の和音を選ぶ場所 |
| 主操作 | 本線のノードを選ぶ（その枠を選ぶ）。探索のタブでは、枝に触れて聴き、確定する（4 の表） |
| 常に出す | 本線のノード（和音名、ローマ数字）。ノードをつなぐ線と、線に載せる読みの判定（解決、終止）。選んでいるノード |
| 必要なときだけ出す | 探索のタブの枝と、探索の足跡。鳴っているノード、試聴中の枝 |
| 出さない | 候補の全部。詳しい札と説明の文（文脈の欄に出す）。枠の長さの編集（帯で行う） |
| 満たす体験 | E1、E2、E3、E5 |

- 線に載せるのは、エンジンの読みが返す判定だけ。読みが付けない名前を、画面で付けない（終止はフレーズの終わりにだけ付く。`docs/architecture/theory-conventions.md` の 4）。
- 判定は、形と語で示す。色だけで示さない。

### 帯

| 項目 | 約束 |
| --- | --- |
| 主目的 | 時間の配置（枠の長さ、小節、フレーズの区切り）を見せ、進行を鳴らす |
| 主操作 | 進行を鳴らす・止める。枠を選ぶ。枠の長さを変える |
| 常に出す | 枠を時間の順に。小節の目盛りと、フレーズの区切り。再生の操作とテンポ |
| 必要なときだけ出す | 鳴っている枠の印。枠を縮めた知らせ。役割を置いた枠の役割と、役割に合うか |
| 出さない | 候補。説明の文 |
| 満たす体験 | E2、E3、E4 |

- 帯で選んだ枠と、キャンバスで選んだ本線のノードは、同じものを指す。片方で選ぶと、もう片方も選んだ見た目になる。

### 文脈の欄

| 項目 | 約束 |
| --- | --- |
| 主目的 | 選んでいるものの理由と、それに対してできることを、全体の隣に出す |
| 主操作 | 理由を読む。試聴する。採る（枝を確定する、枠を埋める候補を入れる、変形を選ぶ） |
| 常に出す | 何を選んでいるか（和音名と、進行の中の位置） |
| 必要なときだけ出す | 選んでいる枝の理論上の説明と期待する印象〔#204〕。詳しい札（種別、機能、借り先、解決、終止、調の外の音、役割に合うか、合わない理由）。選んでいる枠の変形。計画のタブでは、枠を埋める候補 |
| 出さない | 選んでいないものの説明 |
| 満たす体験 | E1、E3、E4 |

- 理論上の説明と期待する印象は、分けて出す（`docs/architecture/explanations.md`）。
- 既定で何を出し、何を開いて見せるか（説明の粒度）は、コンセプトの 8 章で決める。どの粒度でも、段は 2 つまでにする（7 の段階的開示）。

### 探索のタブ（体験 A）

| 項目 | 約束 |
| --- | --- |
| 主目的 | 末尾から伸びる枝を比べて選び、進行を 1 つずつ伸ばす |
| 主操作 | 枝に触れて聴く → 一言で見比べる → 文脈の欄で理由を読む → 確定する。確定すると、枝が本線のノードになり、新しい末尾から次の枝が伸び、フォーカスは最初の枝に戻る |
| 常に出す | 末尾からの枝。枝の数と選び方〔#203〕。各枝の一言〔#204〕 |
| 必要なときだけ出す | 探索の足跡（1 歩前の分岐） |
| 出さない | 候補の全部を一度に |
| 満たす体験 | E1、E2、E5 |

### 計画のタブ（体験 B）

| 項目 | 約束 |
| --- | --- |
| 主目的 | 先に枠と役割を置き、役割に合う候補で埋める |
| 主操作 | 枠に役割を置く。枠を選ぶ → 文脈の欄の候補を試聴する → 入れる。入れると、次の空いた枠へ進む |
| 常に出す | 帯の枠ごとの役割と、役割に合うか |
| 必要なときだけ出す | 選んでいる枠を埋める候補と、合わない理由 |
| 出さない | 選んでいない枠の候補 |
| 満たす体験 | E4、E1、E3 |

## 4. グラフ型の 4 点の置き場所

| | 点 | 区画 | 操作と見え方 |
| --- | --- | --- | --- |
| 1 | 触れると鳴る | キャンバスの枝（探索のタブ） | 枝を選ぶかフォーカスすると、すぐ「前の枠 + 候補」が鳴る。確定は Enter かダブルクリック。キーボードだけで、枝を移り、聴き、確定できる |
| 2 | 枝に一言 | キャンバスの枝（探索のタブ） | 枝に、期待する印象の一言を出す。開かずに見比べられる〔#204〕 |
| 3 | 探索の足跡 | キャンバス（探索のタブ） | 1 歩前の分岐を薄く残し、足跡の枝から選び直せる |
| 4 | 線が意味を運ぶ | キャンバスの線（両方のタブ） | 確定した線に、読みの判定（解決、終止）を形と語で載せる |

## 5. 前提が決まるまでの暫定

#203 と #204 が決まるまで、目標の画面は次で動く。

- 枝は、今の末尾の候補の並び（`POST /progressions/next-candidates` の順）の先頭から数個。先頭は同じまとまり（ダイアトニック）に偏り、意図の違う候補になるとは限らない。
- 枝に一言を出さない。
- 文脈の欄は、理論上の説明と期待する印象の文の代わりに、今の札（短い印と詳しい札。`docs/architecture/screen.md` の「札の語」）を出す。

## 6. まだ決まっていないこと

- 枝の数と選び方、枝にしなかった候補の見せ方、計画のタブで役割で候補を絞るか（#203）。
- 枝の一言と、理論上の説明と期待する印象の文（#204）。
- 既定で何を出し、何を開いて見せるか（コンセプトの 8 章の説明の粒度）。
- 区間の見せ方と、区間に役割を置くこと、フレーズの区切りを動かすこと（#18）。
- 本線のノードから、変形と差し替えを枝として出すか。決まるまで、変形は文脈の欄に出す。
- 短い印（種別、機能、調の外の音）を、キャンバスのノードと帯にも出すか。
- 区画の位置と大きさ。片方のタブの操作（枝、役割を置く）を、もう片方のタブにも出すか。
- 狭い幅の配置。
- 移調（2）の作り方。和音名を変えて返すには API の変更が要るので、器のスライス（#206）と今回のゴール（#196）の範囲の外に置く。それまで、調を変えると、和音名はそのままで読み直す。

## 7. 根拠にした HCI の索引の項目

`.claude/skills/hci/index.md` の項目。

- **選択的注意と近接（関係するものは隣に）**: 文脈の欄を、選んでいるものに追随させ、キャンバスと帯の隣に置く。選んでいる 1 点とその理由のあいだに、スクロールが要らない（E3）。知らせは、今見ている区画の中に出す。
- **段階的開示**: 枝の一言で見比べ、選んだ枝の理由は文脈の欄で読む。段は 2 つまでにし、3 段以上にしない。どの段に何を置くかは、説明の粒度（6）で決める。
- **既定値の力と、選択肢の数**: 並びの先頭は、選ばれやすい。枝の先頭が「正解」に見えないよう、意図の違いで選ぶ規則を #203 で決める。枝の数は、選択肢の数の一般則では決めない。
- **モードとモードエラー、使う人が保つモード**: タブはモードなので、次を守る。
  - どちらのタブかを、2 つ以上の手がかりで示す。
  - 同じ名前の操作は、どちらのタブでも同じ結果になる。タブによって違うことをする操作には、違う名前を付ける。
  - タブを切り替えても、進行は変わらない。取り違えても、元に戻すで戻せる。
- **動きと「動きを減らす」設定**: 枝が伸びる、足跡が薄れるなどの動きは演出で、`prefers-reduced-motion: reduce` では即時の切り替えにする。どの枝を試聴しているか、どの枠が鳴っているかは、動きがなくても分かる形で示す。

キャンバスの上で直接選ぶこと（直接操作）には、確かめた索引の項目がない。出どころを開けず、索引の「外したもの」に置いている（ADR-0019）。

# hci

`index.md` は、chord-rambler の画面と操作を決めるときに当たるべき HCI の知見の索引である。決定の理由は ADR-0018。体験の基本原則（`docs/product/concept.md` の 2 章）を置き換えず、その原則を画面に落とすときの根拠と、よくある誤用を持つ。項目は「どの判断を助けるか」で節に分け、分野（知覚・記憶・…）では分けない。

## 使い方

1. 決めようとしていることを 1 行で言う（例: 「選んだ枠の詳しい札を、帯の隣に出すか下に出すか」「試聴中をどう示すか」）。
2. `index.md` の節の見出しから当たりをつけ、各項目の「当たるべき場面」で絞る。
3. 見つかったら「判断の問い」を自分の案に当て、答えを PR の「当たった索引の項目」に 1〜2 行で書く。項目名を書けば、根拠は索引を引けば分かる。
4. **数値（秒、文字数、px、比）を根拠に使うときは、その項目の一次情報を開いてから使う。** 「確からしさ」の欄に「実務の経験則」「観察」とあるものは、数値ではなく向き（大きいほど／近いほど）だけを使う。開けなければ、開けなかったことを PR か Issue に書き、推測で数値を書かない。
5. 「よくある誤用」に自分の案が当たっていないか見る（7 を項目数の上限にする、など）。
6. 見直しの期限（確認日 + 間隔）を過ぎた項目を根拠に使うときは、先に一次情報を開き直す。手順は `docs/dev/knowledge-review.md`。
7. 見つからなければ、そう書いて進める。足すべき知見だと思ったら、観察の Issue にする（今の作業に混ぜない）。

## 書くもの・書かないもの

- 書く: 名前、出典（著者・年・題・合法に読める URL）、何を言っているか（自分の言葉で 2〜4 行）、確からしさ（実験の積み重ね／観察／実務の経験則／規範、とよくある誤用）、当たるべき場面、判断の問い、適切・不適切な例、chord-rambler との接点、確認日。
- 書かない: 本や論文の文章の引用、図表の写し、一次情報を開かずに書いた中身、違法なアップロードへのリンク。
- 確認日は、一次情報か権威ある公開資料（著者の公開版、W3C、MDN、NN/g など）を実際に開いて確かめた日。何を開いたかを欄に書く。原論文が開けず解説だけで確かめたものは、そう書き、原論文の中身は書かない。どれも開けなかった項目は「未確認（理由）」とし、次に開けたら更新する。
- 「外したもの」の節に、検討して外した知見と理由（chord-rambler に関係が薄い、一次情報を開けなかった、ほかの項目と重複）を残す。再び提案されたときに同じ検討を繰り返さないため。
- 個別の課題への当てはめ（今の画面をどう直すか）は、索引ではなく Issue に書く。索引は課題をまたいで使える形だけを持つ。

## ほかの索引との分担

| 索引 | 中身 | 引く場面 |
| --- | --- | --- |
| `.claude/skills/practices/index.md` | 開発の知見（機械で検出できない判断） | 設計・実装・レビューで、テストや抽象や境界を決めるとき |
| `.claude/skills/standards/index.md` | 業界標準と、その一次情報の場所（WCAG 2.2 そのものも、ここ） | ファイル形式・記法・プロトコルを決めるとき、適合のレベルや検査を決めるとき |
| `index.md`（この索引） | HCI の知見と、判断の問い（WCAG の個々の達成基準を、画面の判断の根拠として引く） | 画面・操作・フィードバック・配置・色を決める・変えるとき |

## 項目の形

項目は `###` の見出しと、次の欄を持つ表。節（`##`）は、助ける判断ごとに分ける。表の中に `|` を書かない。URL のすぐ後ろには空白を置く（鮮度の報告が URL を切り出すため）。

| 欄 | 書き方 |
| --- | --- |
| 出典 | 著者・年・題と URL。開けなかった原論文は名前だけにし、確認日の欄にそう書く |
| 何を言っているか | 開いたものに書かれていることを、自分の言葉で 2〜4 行 |
| 確からしさ | 根拠の種類と強さ。よくある誤用 |
| 当たるべき場面 | どの判断のときに引くか |
| 判断の問い | 自分の案に当てる問い |
| 適切・不適切な例 | 画面の例 |
| chord-rambler との接点 | 今の画面（`docs/architecture/screen.md`）とコンセプト（`docs/product/concept.md`）のどこに効くか |
| 確認日 | `YYYY-MM-DD / 間隔 N 日（開いたもの。開けなかったもの）`。どれも開けなかったときは `未確認（理由）` |
